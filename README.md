# Vendor Relationship Dashboard

An interactive, sanitized map of public professional relationships across end clients, staffing vendors, account managers, and recruiters.

## Privacy boundary

This public repository contains no email addresses, resumes, application history, submission records, correspondence, or private notes. Dashed relationships are research prospects and must not be treated as verified account ownership.

## View locally

Open `index.html` in any modern browser. The page is self-contained and has no external JavaScript, analytics, package installation, or build step.

## Status key

- **Confirmed:** Supported by direct or independently verified evidence.
- **Prospect:** A research lead that still requires verification.
- **Unknown:** A relationship slot has been identified, but the appropriate person has not.
